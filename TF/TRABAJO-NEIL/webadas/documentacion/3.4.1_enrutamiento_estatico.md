# 3.4.1 Implementacion de enrutamiento dinamico y estatico

## Enrutamiento dinamico WAN interna

### ROUTER_LIMA

```cisco
enable
configure terminal
interface Serial0/0/0
 description WAN a ROUTER_LA_LIBERTAD
 ip address 10.192.60.1 255.255.255.252
 clock rate 64000
 no shutdown
exit
interface Serial0/0/1
 description WAN a ROUTER_ICA
 ip address 10.192.60.5 255.255.255.252
 clock rate 64000
 no shutdown
exit
interface Serial0/1/0
 description WAN a ROUTER_HUANUCO
 ip address 10.192.60.9 255.255.255.252
 clock rate 64000
 no shutdown
exit
interface Serial0/1/1
 description WAN a ROUTER_PUNO
 ip address 10.192.60.13 255.255.255.252
 clock rate 64000
 no shutdown
exit
router rip
 version 2
 no auto-summary
 network 10.0.0.0
 default-information originate
end
```

## Enrutamiento estatico de Internet

### ROUTER_LIMA

```cisco
enable
configure terminal
no ip domain-lookup
hostname ROUTER_LIMA
interface Serial0/2/0
 ip address 219.0.0.1 255.255.255.252
 clock rate 64000
 no shutdown
exit
interface Serial0/2/1
 ip address 219.0.0.5 255.255.255.252
 clock rate 64000
 no shutdown
exit
ip route 0.0.0.0 0.0.0.0 219.0.0.2
ip route 0.0.0.0 0.0.0.0 219.0.0.6 10
end
```
