# Verificacion de enrutamiento dinamico y estatico

## Verificacion de RIP

```cisco
show ip protocols
show ip route
show ip route rip
show running-config | section router rip
```

## Verificacion de rutas estaticas

```cisco
show ip route static
show running-config | include ^ip route
```

## Pruebas desde ROUTER_LIMA hacia sedes

```cisco
ping 10.192.44.1
ping 10.192.48.1
ping 10.192.52.1
ping 10.192.56.1
traceroute 10.192.44.1
traceroute 10.192.48.1
traceroute 10.192.52.1
traceroute 10.192.56.1
```

## Pruebas desde sedes remotas hacia Lima
