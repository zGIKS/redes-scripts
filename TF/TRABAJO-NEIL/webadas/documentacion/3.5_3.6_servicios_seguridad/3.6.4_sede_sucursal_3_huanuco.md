# 3.6.4 Sede sucursal 3 - Huanuco

## Primera politica de seguridad

```cisco
enable
configure terminal
ip access-list standard MGMT_HUANUCO
 permit 10.192.52.160 0.0.0.15
 permit 10.192.42.176 0.0.0.15
deny any
exit
line vty 0 4
 access-class MGMT_HUANUCO in
 transport input ssh
 login local
 exec-timeout 10 0
exit
end
```

## Segunda politica de seguridad

```cisco
enable
configure terminal
ip access-list extended FTP_HUANUCO
 permit tcp 10.192.52.0 0.0.3.255 host 10.192.52.181 eq 21
 permit tcp 10.192.40.0 0.0.3.255 host 10.192.52.181 eq 21
 deny tcp any host 10.192.52.181 eq 21
 permit ip any any
exit
interface GigabitEthernet0/0.47
 ip access-group FTP_HUANUCO in
exit
end
```
