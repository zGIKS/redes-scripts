# 3.6.3 Sede sucursal 2 - Ica

## Primera politica de seguridad

```cisco
enable
configure terminal
ip access-list standard MGMT_ICA
 permit 10.192.49.32 0.0.0.15
 permit 10.192.42.176 0.0.0.15
deny any
exit
line vty 0 4
 access-class MGMT_ICA in
 transport input ssh
 login local
 exec-timeout 10 0
exit
end
```

## Segunda politica de seguridad

```cisco
enable
configure terminal
ip access-list extended FTP_ICA
 permit tcp 10.192.48.0 0.0.3.255 host 10.192.49.69 eq 21
 permit tcp 10.192.40.0 0.0.3.255 host 10.192.49.69 eq 21
 deny tcp any host 10.192.49.69 eq 21
 permit ip any any
exit
interface GigabitEthernet0/0.27
 ip access-group FTP_ICA in
exit
end
```
